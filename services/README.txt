PHC and octboot_net userspace driver
====================================

Introduction
------------

PHC user space driver is used to read octeon timestamp register from user space, hence  a user space program can read the time offset
from octeon register and can use this to adjust host system clock similar to phc2sys app.

Octboot_net user space program provides a TAP interface to communicate to octeon uboot eth0 or dpi eth interface.
TAP interface provided by octboot_net can be used to transfer firmware images to uboot and hence update the firmware on octeon.

Compilation
-----------
Go to services directory and follow below steps.

1.	Install pciutils-devel.x86_64
	#	yum install pciutils-devel.x86_64

2.	Install fuse-devel.x86_64
	#	yum install fuse-devel.x86_64

3.	Install pkgconf-pkg-config.x86_64
	#	yum install pkgconf-pkg-config.x86_64

4.	Do make under services directory.
	#	make

	To compile with PHC_SUPPORT
	$ make PHC_SUPPORT=1


After following above steps, we get  daemon_test execuatble in services dir.

Reading PHC timestamp
---------------------

Go to services directory.

1.	Execute daemon_test executable as follows.
	#	./daemon_test

2.	Now, compile sample test program as follows.
	# gcc -o read_phc read_file.c

3.	Read timestamp value by running read_phc as follows,
	mrvl_ptp[0...1] device can be found in /dev/.

	#	./read_phc /dev/mrvl_ptp[0...]
	
The output generated by read_phc is time stamp value in hex format.


Using octboot_net interface
---------------------------


Go to services directory.

1.	Execute daemon_test executable as follows.
	#	./daemon_test
	
2.	After running daemon_tets program octboot_net<0..> interface gets created,
	assign an IP to that interface, example: 
	#	ifconfig octboot_net0 192.168.10.2/24 up

3.	Assign IP to uboot dpi_pf interface.
	Goto octeon uboot prompt and run below commands.

	#	setenv ethact eth0
	#	setenv ipaddr 192.168.10.4

4.	Run tftpboot from uboot prompt as follows.

	#	tftpboot $loadaddr 192.168.10.2:<imagefile>
